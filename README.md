# Wide Residual Networks：CIFAR-10 重現

論文：Zagoruyko 與 Komodakis，[Wide Residual Networks（arXiv v4）](https://arxiv.org/abs/1605.07146v4)。

## 論文摘要

圖片辨識模型常靠增加層數提升能力，但層數太多，訓練可能變慢，進步也有限。這篇論文提出「寬殘差網路（WRN）」：增加每層能學習的特徵數量，讓較少層數的模型也能有好的辨識效果。

## 本篇論文目的

研究模型是否一定要越深越好，並找出能兼顧辨識效果與運算速度的寬度、深度及區塊設計。

## 研究方法

作者比較不同層數、寬度與區塊結構，測試 dropout（訓練時隨機暫時關閉部分訊號）的效果，並在 CIFAR-10、CIFAR-100、SVHN、ImageNet 與 COCO 等任務上評估辨識表現及運算效率。

本專案選擇重現 WRN-16-8 的 CIFAR-10 實驗：使用平均值與標準差調整圖片數值，搭配翻轉、反射補邊與隨機裁切；不使用 dropout，每批 128 張圖片、訓練 200 輪，取五次結果的中位數。

## 呈現的成果

論文顯示，適當加寬的模型可以用較少層數達到更好的辨識效果，部分設定的運算速度也更快；dropout 則能改善部分模型的表現。

以下對照論文第 8 頁 Table 5 的 WRN-16-8 結果，錯誤率越低越好：

| 項目 | 原論文 | 本專案 |
|---|---:|---:|
| CIFAR-10 錯誤率（五次中位數） | 4.27% | 4.40% |
| 對應準確率 | 95.73% | 95.60% |

本專案比論文多 0.13 個百分點的錯誤率，約相當於每 10,000 張圖片多錯 13 張，數字接近，仍有差距。本專案涵蓋這項 CIFAR-10 實驗。
